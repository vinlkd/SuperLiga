# Equipes e jogadores

1. Na tela Times, informe o nome e, opcionalmente, uma imagem.
2. Abra Visualizar para acessar o elenco.
3. Cadastre nome, número da camisa e posição de cada jogador.
4. Use Editar para corrigir dados antes de montar a súmula.

O nome do time deve ter até 80 caracteres. A imagem aceita deve declarar um tipo image/ e ter até 1,5 MB; o limite total da requisição é 2.000.000 bytes.

Cada time aceita até 12 jogadores. As camisas vão de 0 a 99 e não podem se repetir no mesmo time. O cadastro impede nomes normalizados de jogadores repetidos, inclusive entre equipes.

As posições disponíveis são Levantador e Atacante. Para iniciar uma partida, cada time precisa fornecer seis titulares diferentes: dois levantadores e quatro atacantes.

A exclusão de time também exclui suas partidas. Confira o impacto antes de confirmar a ação na interface.
